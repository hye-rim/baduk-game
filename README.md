# 바둑 ⚫⚪

9×9 판에서 컴퓨터와 한 판 두는 바둑입니다. 서버 없이 `index.html` 만 열면 돌아갑니다.

- 조작: 점을 눌러 고르고(반투명 돌) **착수** 버튼이나 같은 점을 한 번 더 눌러 둡니다(폰에서 잘못 누르는 것을 막으려고 두 단계). **패스**, **무르기**(내 수와 컴퓨터의 수 한 쌍), **추천**(컴퓨터가 고른 자리를 파란 원으로), **기권**. 키보드: `Enter` 착수, 방향키로 점 이동, `P` 패스, `U` 무르기, `M` 소리. 내 돌 색(흑 먼저 / 백 나중)은 시작 화면에서 고릅니다.
- 규칙과 컴퓨터는 `logic.js`(DOM 없음), 화면·소리·입력은 `game.js`. 시험: `node --test`.

## 규칙 (한국식)
- 교차점에 흑이 먼저 번갈아 돌을 놓습니다. 같은 색으로 이어진 돌 덩어리는 이웃한 빈 점(**활로**)이 모두 막히면 잡혀 판에서 사라집니다.
- **자충수 금지**: 둔 돌(덩어리)의 활로가 없어지는 곳에는 둘 수 없습니다. 단, 그 수로 상대 돌을 잡으면 둘 수 있습니다.
- **패(코) 금지**: 같은 판 모양이 다시 나오게 하는 수는 둘 수 없습니다(처음부터 지금까지의 모든 모양과 비교하므로 한 수 걸러서도 같은 모양을 만들 수 없습니다). 화면에 패 자리를 붉은 네모로 표시합니다.
- 둘 곳이 없으면 **패스**합니다. 양쪽이 연달아 패스하면 대국이 끝나고 **계가**로 갑니다.
- **계가**: 먼저 컴퓨터가 몬테카를로 시험으로 **죽은 돌**을 짐작해 ✕ 로 표시합니다. 돌을 누르면 그 덩어리가 살았다/죽었다로 바뀝니다. 맞으면 「계가 확정」, 아직 끝난 게 아니라고 생각하면 「계속 두기」.
- **점수** = 집(살아 있는 한 쪽 돌에만 둘러싸인 빈 곳) + 대국 중에 잡은 돌 + 죽은 돌로 표시한 상대 돌 수. 백에게는 **덤 6.5집**을 더합니다(흑이 먼저 두는 대가). 공배(양쪽에 닿는 빈 곳)는 아무에게도 안 갑니다.
- **난이도**: 「쉬움」은 컴퓨터가 120번쯤 시험해 보고 절반쯤은 바로 보이는 잡기·살리기를 놓칩니다(0.2초 안팎). 「보통」은 약 1.4초 동안 수천 번 시험합니다. 쉬움에서는 최고 기록(이긴 집 수)이 저장되지 않습니다.

## 컴퓨터는 어떻게 두나
- **몬테카를로 나무 탐색**: 각 후보 수에서 무작위로 끝까지 두어 보고(눈 메우기와 직전 수 근처 우선 같은 단순한 규칙 포함) 이기는 비율이 높은 수를 고릅니다. 초반에는 가장자리보다 중앙 쪽을 약간 선호하고, 바로 잡을 수 있는 돌(안전할 때)과 한 수 남은 내 돌을 살리는 수는 먼저 둡니다. 상대가 패스했고 이기고 있으면 패스해서 끝냅니다.
- 시험에서 시험 횟수 1000회 컴퓨터가 60회 컴퓨터를 12판 중 11판 이겼습니다(실력이 시험 횟수에 따라 오릅니다). **사람과 비교한 실력은 측정하지 못했습니다.** 대략 입문~초급 정도로 보시면 됩니다.

## 참고한 것과 제가 정한 값
- 판 크기 9×9, 덤 6.5집(한국·일본식), 집 + 잡은 돌 계산은 공개 자료([위키백과 덤](https://ko.wikipedia.org/wiki/%EB%8D%A4_(%EB%B0%94%EB%91%91)), [나무위키 국가별 룰](https://namu.wiki/w/%EB%B0%94%EB%91%91/%EA%B5%AD%EA%B0%80%EB%B3%84%20%EB%A3%B0))을 따랐습니다. 중국식은 집 + 살아 있는 돌을 세고 덤이 7.5집입니다.
- 제가 정한 값: 죽은 돌 판정 방법(무작위 시험으로 짐작하고 사람이 고침), 패 판정을 「같은 모양 반복 금지」로 일반화한 것, 컴퓨터의 시험 횟수·시간, 무르기 횟수 무제한, 접바둑(돌 미리 놓기)과 시간 제한은 없음. 온라인 대전은 없습니다.
